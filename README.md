# URL Shortener

Project structure for a URL shortener application.

## Folders

- `frontend/` - Client-side application code.
- `backend/` - Server-side API and application logic.
- `database/` - Database schema, migrations, seeds, or setup files.

## Backend Structure

- `backend/api/` - Receives HTTP requests, validates input, calls the service layer, and builds HTTP responses.
- `backend/service/` - Contains business logic and decides what the application should do.
- `backend/repositories/` - Handles persistence operations such as insert, select, update, and delete.
